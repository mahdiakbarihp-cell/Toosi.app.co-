راهنمای ساختار پوشه‌ها و بارگذاری روی هاست (TOOSI.APP.CO)
========================================================

1. فایل‌های HTML را در مسیر اصلی هاست (معمولاً public_html) قرار دهید.
2. پوشه images را نیز در کنار فایل‌های HTML آپلود کنید.

ساختار پوشه تصاویر (images):
- images/background/
    -> عکس پس‌زمینه اصلی را دقیقاً با نام 1000233278_2.jpg اینجا بگذارید.
- images/logo/
    -> لوگوی سایت را با نام logo.png اینجا بگذارید (به صورت خودکار کنار نام برند در هدر نمایش داده می‌شود).
- images/hero/
    -> تصاویر بخش Hero و بنرهای اصلی را اینجا قرار دهید.
- images/electrical-projects/
    -> تصاویر پروژه‌های برق (در صورت قرار دادن فایل cover.jpg، به صورت کاور محو داخل مستطیل اول نمایش داده می‌شود).
- images/app-projects/
    -> تصاویر پروژه‌های App (در صورت قرار دادن فایل cover.jpg، داخل مستطیل دوم نمایش داده می‌شود).
- images/design-build-projects/
    -> تصاویر پروژه‌های طراحی ساخت (در صورت قرار دادن فایل cover.jpg، داخل مستطیل سوم نمایش داده می‌شود).
- images/projects-in-development/
    -> تصاویر پروژه‌ها و برنامه‌های در حال توسعه (در صورت قرار دادن فایل cover.jpg، داخل مستطیل چهارم نمایش داده می‌شود).
